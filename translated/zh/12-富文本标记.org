* 富文本标记

Org 支持多种文本标记格式。

** 基本标记

| 标记 | 效果 | 说明 |
|------+------|------|
| =*粗体*= | *粗体* | 用星号包裹 |
| =/斜体/= | /斜体/ | 用斜杠包裹 |
| =_下划线_= | _下划线_ | 用下划线包裹 |
| =+删除线+= | +删除线+ | 用加号包裹 |
| ==代码== | =代码= | 用等号包裹 |
| =~源码~= | ~源码~ | 用波浪号包裹 |

** 组合标记

可以组合使用：

#+BEGIN_EXAMPLE
*/粗斜体/*
_+下划线加删除线+_
#+END_EXAMPLE

** 上标和下标

#+BEGIN_EXAMPLE
H_2O 是水分子
E=mc^2 是爱因斯坦方程
a^{b}_{c} 复杂上下标
#+END_EXAMPLE

** 特殊字符

- =\--- 破折号
- =\...= 省略号
- =\-= 软换行
- =\%= 注释

** 实体

使用 LaTeX 风格的实体：

- =\alpha= → α
- =\beta= → β
- =\gamma= → γ
- =\pi= → π
- =\infty= → ∞
- =\to= → →
- =\Rightarrow= → ⇒
- =\Leftarrow= → ⇐

** 宏

定义可复用的文本：

#+BEGIN_EXAMPLE
#+MACRO: version 9.8
#+MACRO: date 2024-01-15

当前版本: {{{version}}}
日期: {{{date}}}
#+END_EXAMPLE
