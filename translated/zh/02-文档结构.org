* 文档结构

Org 文档使用大纲结构。标题（headlines）形成顶级结构，每个标题下可以有子标题、段落、列表等内容。

** 标题

标题是 Org 文档的基本结构单元。标题以星号开头：

#+BEGIN_EXAMPLE
* 一级标题
** 二级标题
*** 三级标题
**** 四级标题
#+END_EXAMPLE

一个标题至少需要一个星号，可以有多个。标题数量决定了层级深度。

标题可以包含 TODO 关键字、标签和优先级：

#+BEGIN_EXAMPLE
* TODO 带任务状态的标题
* DONE 已完成的任务
* TODO [#A] 高优先级任务   :work:urgent:
#+END_EXAMPLE

** 可见性折叠

Org 模式的一个强大特性是可以折叠和展开大纲。这让您专注于当前正在处理的部分。

主要命令：

| 快捷键       | 功能                         |
|-------------+------------------------------|
| =TAB=       | 切换当前条目的可见性           |
| =S-TAB=     | 全局切换可见性（三种状态循环） |
| =C-c C-r=   | 显示当前条目的内容             |

*** 全局和局部折叠

=TAB= 在当前条目上循环三种状态：

1. *折叠*：只显示标题
2. *子树*：显示该标题下的所有子标题
3. *全部*：显示所有文本

=S-TAB= 在整个文档中循环：

1. *折叠*：只显示顶级标题
2. *子树*：显示所有标题
3. *全部*：显示所有内容

*** 初始可见性

可以通过在文件开头添加 =STARTUP= 选项设置初始状态：

#+BEGIN_EXAMPLE
#+STARTUP: fold        # 初始折叠
#+STARTUP: showall     # 初始展开所有内容
#+STARTUP: showeverything  # 显示所有内容
#+END_EXAMPLE

** 移动

在标题间移动的命令：

| 快捷键     | 功能                    |
|-----------+-------------------------|
| =C-c C-n= | 下一个标题              |
| =C-c C-p= | 上一个标题              |
| =C-c C-f= | 下一个同级标题          |
| =C-c C-b= | 上一个同级标题          |
| =C-c C-u= | 上一级标题              |

** 结构编辑

| 快捷键       | 功能                         |
|-------------+------------------------------|
| =M-RET=     | 插入新标题                   |
| =M-S-RET=   | 插入新 TODO 标题             |
| =M-LEFT=    | 提升标题（减少星号）         |
| =M-RIGHT=   | 降低标题（增加星号）         |
| =M-S-UP=    | 向上移动标题及其子树         |
| =M-S-DOWN=  | 向下移动标题及其子树         |

** 稀疏树

Org 可以根据条件显示"稀疏树"——只显示匹配条件的标题。

主要命令：

- =C-c /=：打开稀疏树命令前缀
- =C-c / t TODO=：显示所有 TODO 状态为 TODO 的条目
- =C-c / m work|urgent=：显示包含 work 或 urgent 标签的条目

** 纯列表

Org 支持纯列表（无序和有序）：

#+BEGIN_EXAMPLE
- 无序列表项
- 另一个列表项
  - 子项
  - 另一个子项

1. 有序列表
2. 第二项
3. 第三项
#+END_EXAMPLE

在列表上：

- =TAB=：折叠/展开列表项
- =M-RET=：新建列表项
- =M-S-RET=：新建 TODO 列表项

** 抽屉

抽屉（Drawers）用于存储隐藏的信息：

#+BEGIN_EXAMPLE
* 一个条目
:PROPERTIES:
:CATEGORY: 工作
:END:

这是条目的内容。

:LOGBOOK:
- 2024-01-15: 创建
:END:
#+END_EXAMPLE

常用抽屉：

- =PROPERTIES=：存储属性
- =LOGBOOK=：存储日志

** 块

Org 支持多种特殊块：

#+BEGIN_EXAMPLE
#+BEGIN_QUOTE
引用文本
#+END_QUOTE

#+BEGIN_VERSE
  保留空格的
    诗歌格式
#+END_VERSE

#+BEGIN_EXAMPLE
示例代码
#+END_EXAMPLE

#+BEGIN_SRC emacs-lisp
;; 源代码块
(message "Hello!")
#+END_SRC
#+END_EXAMPLE
