* 表格

Org 提供了一个内置的表格编辑器，可以创建简单的表格。

** 基本表格

表格使用管道符号 =|= 分隔列：

#+BEGIN_EXAMPLE
| 名称 | 年龄 | 城市 |
|------+------|------|
| 张三 |   25 | 北京 |
| 李四 |   30 | 上海 |
| 王五 |   28 | 广州 |
#+END_EXAMPLE

输入 =|= 后按 =TAB= 可以快速创建表格：

#+BEGIN_EXAMPLE
| Name | Phone | Age |
#+END_EXAMPLE

按 =TAB= 后自动对齐。

** 表格编辑器命令

| 快捷键 | 功能 |
|--------+------|
| =TAB= | 对齐表格并移动到下一列 |
| =S-TAB= | 对齐表格并移动到上一列 |
| =RET= | 对齐表格并移动到下一行 |
| =C-c SPC= | 清空单元格 |

*** 列操作

| 快捷键 | 功能 |
|--------+------|
| =M-LEFT= | 向左移动列 |
| =M-RIGHT= | 向右移动列 |
| =M-S-LEFT= | 删除当前列 |
| =M-S-RIGHT= | 插入新列 |
| =C-c -= | 插入水平分隔线 |

*** 行操作

| 快捷键 | 功能 |
|--------+------|
| =M-UP= | 向上移动行 |
| =M-DOWN= | 向下移动行 |
| =M-S-UP= | 删除当前行 |
| =M-S-DOWN= | 在下方插入行 |

** 列宽和对齐

可以设置列的显示宽度：

#+BEGIN_EXAMPLE
| <5> | <10> | <> |
| 短 | 这是较宽的列 | 自动 |
| 文本 | 更多文本内容 | 宽度 |
#+END_EXAMPLE

=<N>= 设置固定宽度，=<>= 自动宽度。

按 =C-c C-c= 应用对齐设置。

** 电子表格

Org 表格可以作为电子表格使用，支持公式计算。

*** 引用

| 语法 | 含义 |
|------+------|
| =@2$3= | 第 2 行第 3 列 |
| =$3= | 当前行第 3 列 |
| =@2= | 第 2 行 |
| =$>= | 最后一列 |
| =@>= | 最后一行 |

*** 范围

| 语法 | 含义 |
|------+------|
| =$1..$3= | 第 1 到第 3 列 |
| =@2..@4= | 第 2 到第 4 行 |
| =$1..$>= | 第 1 列到最后一列 |

*** 公式

公式放在 =#+TBLFM:= 行中：

#+BEGIN_EXAMPLE
| 商品 | 单价 | 数量 | 总价 |
|------+-------+--------+------|
| 苹果 | 5.00 | 3 | 15.00 |
| 香蕉 | 3.50 | 2 | 7.00 |
| 橙子 | 4.00 | 4 | 16.00 |
|      |      |      | 38.00 |
#+TBLFM: $4=$2*$3::@5$4=vsum(@2..@4)
#+END_EXAMPLE

公式语法：

- =$4=$2*$3=：第 4 列 = 第 2 列 × 第 3 列
- =@5$4=vsum(@2..@4)=：第 5 行第 4 列 = 第 2-4 行的和

*** 常用函数

| 函数 | 功能 |
|------+------|
| =vsum= | 求和 |
| =vmean= | 平均值 |
| =vmin= | 最小值 |
| =vmax= | 最大值 |
| =vcount= | 计数 |

** 导出表格

表格可以导出为多种格式：

- HTML
- LaTeX
- CSV
- 等等

#+BEGIN_EXAMPLE
#+CAPTION: 销售数据表
#+NAME: tab:sales
| 月份 | 销售额 |
| 1月 | 100 |
| 2月 | 120 |
#+END_EXAMPLE
