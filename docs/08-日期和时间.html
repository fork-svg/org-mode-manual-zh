日期和时间

Org 模式有强大的日期和时间处理功能。

时间戳

时间戳是插入在文本中的日期信息。

活跃时间戳

活跃时间戳会出现在日程视图中：

* 会议
<2024-01-15 周一>

* 约会
<2024-01-20 周六 14:00>

* 生日
<2024-03-15 周五 +1y>

格式：

非活跃时间戳

非活跃时间戳不会出现在日程中：

[2024-01-15 周一]
[2024-01-20 周六 14:00]

格式：[YYYY-MM-DD 星期 [HH:MM]]

创建时间戳

快捷键功能
C-c .插入活跃时间戳
C-u C-c .插入非活跃时间戳
C-c ! 插入当前时间
C-c C-y插入时间范围

日期/时间提示

按 C-c . 会弹出日期选择器：

  • 直接输入日期：2024-01-15
  • 相对日期：+3（3天后）
  • 相对星期：+1w（1周后）
  • 相对月：+1m（1月后）
  • 相对年：+1y（1年后）
  • 星期几：mon（下周一）

自定义时间格式

可以设置显示格式：

(setq org-time-stamp-formats
      '("%Y-%m-%d" . "%Y-%m-%d %H:%M"))

截止日期和计划

插入截止日期

* TODO 提交报告
  DEADLINE: <2024-02-01 周四>
快捷键功能
C-c C-d插入截止日期
C-u C-c C-d删除截止日期

插入计划日期

* TODO 开始项目
  SCHEDULED: <2024-01-20 周六>
快捷键功能
C-c C-s插入计划日期
C-u C-c C-s删除计划日期

重复任务

可以设置重复任务：

* TODO 每周例会
  SCHEDULED: <2024-01-22 周一 ++1w>

* TODO 月度报告
  DEADLINE: <2024-01-31 周三 +1m>

* TODO 每年体检
  SCHEDULED: <2024-06-01 周六 .+1y>

重复语法：

  • +1w：每周（从原始日期计算）
  • ++1w：每周（从完成日期计算）
  • .+1w：每周（从完成日期计算，跳过间隔）

工作时间记录

Org 可以记录工作时间（clocking）：

快捷键功能
C-c C-x C-i开始计时
C-c C-x C-o停止计时
C-c C-x C-j跳转到当前计时的任务
C-c C-x C-q取消当前计时

计时记录保存在 LOGBOOK 抽屉中：

* TODO 编写文档
:LOGBOOK:
CLOCK: [2024-01-15 周一 09:00]--[2024-01-15 周一 11:30] => 2:30
CLOCK: [2024-01-16 周二 14:00]--[2024-01-16 周二 16:00] => 2:00
:END:

时间报告表

生成工作时间报告：

#+BEGIN: clocktable :maxlevel 2 :scope file
#+CAPTION: 时间记录表
| 标题 | 时间 |
|--------+------|
| 总计 | 4:30 |
|--------+------|
| 编写文档 | 4:30 |
#+TBLFM: $2='(org-clock-sum-today);T
#+END:

工作时间估算

可以为任务设置时间估算：

* TODO 大项目
  :PROPERTIES:
  :Effort: 1d
  :END:
** TODO 子任务1
   :PROPERTIES:
   :Effort: 2:00
   :END:
