表格

Org 提供了一个内置的表格编辑器，可以创建简单的表格。

基本表格

表格使用管道符号 | 分隔列：

| 名称 | 年龄 | 城市 |
|------+------|------|
| 张三 |   25 | 北京 |
| 李四 |   30 | 上海 |
| 王五 |   28 | 广州 |

输入 | 后按 TAB 可以快速创建表格：

| Name | Phone | Age |

按 TAB 后自动对齐。

表格编辑器命令

快捷键功能
TAB对齐表格并移动到下一列
S-TAB对齐表格并移动到上一列
RET对齐表格并移动到下一行
C-c SPC清空单元格

列操作

快捷键功能
M-LEFT向左移动列
M-RIGHT向右移动列
M-S-LEFT删除当前列
M-S-RIGHT插入新列
C-c -插入水平分隔线

行操作

快捷键功能
M-UP向上移动行
M-DOWN向下移动行
M-S-UP删除当前行
M-S-DOWN在下方插入行

列宽和对齐

可以设置列的显示宽度：

| <5> | <10> | <> |
| 短 | 这是较宽的列 | 自动 |
| 文本 | 更多文本内容 | 宽度 |

设置固定宽度，<> 自动宽度。

按 C-c C-c 应用对齐设置。

电子表格

Org 表格可以作为电子表格使用，支持公式计算。

引用

语法含义
@2$3第 2 行第 3 列
$3当前行第 3 列
@2第 2 行
$>最后一列
@>最后一行

范围

语法含义
$1..$3第 1 到第 3 列
@2..@4第 2 到第 4 行
$1..$>第 1 列到最后一列

公式

公式放在 #+TBLFM: 行中：

| 商品 | 单价 | 数量 | 总价 |
|------+-------+--------+------|
| 苹果 | 5.00 | 3 | 15.00 |
| 香蕉 | 3.50 | 2 | 7.00 |
| 橙子 | 4.00 | 4 | 16.00 |
|      |      |      | 38.00 |
#+TBLFM: $4=$2*$3::@5$4=vsum(@2..@4)

公式语法：

  • $4$2*$3：第 4 列 第 2 列 × 第 3 列
  • @5$4vsum(@2..@4)：第 5 行第 4 列 第 2-4 行的和

常用函数

函数功能
vsum求和
vmean平均值
vmin最小值
vmax最大值
vcount计数

导出表格

表格可以导出为多种格式：

  • HTML
  • LaTeX
  • CSV
  • 等等
