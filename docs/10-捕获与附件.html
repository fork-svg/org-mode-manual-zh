捕获与附件

捕获（Capture）是 Org 模式中快速记录想法和信息的机制。附件功能则允许为条目关联外部文件。

捕获

捕获让你可以快速记录各种信息——待办事项、笔记、日记等——而无需离开当前工作。

捕获模板

捕获模板定义了记录内容的格式和目标位置。

(setq org-capture-templates
      '(("t" "待办事项" entry (file "~/org/inbox.org")
         "* TODO %?\n  %i\n  %a")
        ("n" "笔记" entry (file "~/org/notes.org")
         "* %? :note:\n  %U\n  %i")
        ("j" "日记" entry (file+datetree "~/org/diary.org")
         "* %?\n  %U\n  %i")))

模板格式：(键 描述 类型 目标 模板文本)

模板目标

模板目标指定内容保存的位置：

目标类型说明
(file "路径")追加到文件末尾
(file+headline "路径" "标题")添加到指定标题下
(file+olp "路径" "一级" "二级")添加到指定大纲路径下
(file+datetree "路径")按日期添加到日期树中
(file+function "路径" func)使用自定义函数定位
(clock)添加到当前计时的条目
(function func)使用完全自定义的函数

模板变量

模板文本支持以下变量：

变量含义
%?光标最终位置
%t时间戳（日期）
%T时间戳（日期和时间）
%U非活跃时间戳（日期和时间）
%u非活跃时间戳（日期）
%i选中区域的初始内容
%a当前链接（annotation）
%A当前链接（带描述）
%l原始链接
%c剪贴板内容
%x选中的文本
%^{prompt}提示用户输入
%^t提示 TODO 状态
%^g提示标签
%^{PROP}p提示属性值

捕获流程

1. 按 C-c c 启动捕获

2. 按模板键（如 t）选择模板

3. 在弹出的捕获缓冲区中填写内容

4. 按 C-c C-c 确认保存

5. 按 C-c C-k 取消

快捷键功能
C-c c启动捕获
C-c C-c完成并保存
C-c C-k取消捕获
C-c C-w完成并重新归档
C-c C-r中止并返回

快速捕获

无需选择模板，直接快速记录：

;; 直接捕获（使用默认模板）
(defun my-quick-capture ()
  (interactive)
  (org-capture nil "t"))  ; "t" 是模板键

附件

附件功能允许为 Org 条目关联文件（图片、PDF、代码等）。

附件目录

每个条目可以有一个附件目录来存储关联文件：

;; 设置附件目录位置
(setq org-attach-id-dir "data/")

;; 或使用 ID 作为子目录
(setq org-attach-id-dir
      (expand-file-name "data/" (file-name-directory (buffer-file-name))))

附件命令

快捷键功能
C-c C-a附件命令前缀
C-c C-a a选择附件方法
C-c C-a c复制文件到附件目录
C-c C-a l链接文件（不复制）
C-c C-a m移动文件到附件目录
C-c C-a n添加注释到新附件
C-c C-a s设置附件目录
C-c C-a z同步附件目录
C-c C-a o打开附件
C-c C-a f在文件管理器中打开附件目录
C-c C-a d删除附件
C-c C-a j打开附件并跳转到条目

附件方法

复制文件（c）

C-c C-a c
选择文件: ~/Documents/report.pdf

文件被复制到附件目录中。

链接文件（l）

不复制文件，只创建链接：

C-c C-a l
选择文件: ~/Documents/report.pdf

创建指向原文件的链接。

移动文件（m）

C-c C-a m
选择文件: ~/Downloads/image.png

文件被移动到附件目录中。

从剪贴板粘贴（y）

C-c C-a y
从剪贴板粘贴截图（如果剪贴板包含图片）。

附件 ID

附件使用 ID 属性来标识存储位置：

* 项目文档
  :PROPERTIES:
  :ID:       abc123-def456
  :DIR:      data/ab/c1/abc123-def456
  :END:

查看附件

在带有附件的条目上：

C-c C-a o   → 打开最近的附件
C-c C-a f   → 在文件管理器中浏览附件目录
C-c C-a l   → 列出所有附件

附件与 Git

可以配置 Org 自动将附件提交到 Git：

;; 自动 git add 附件
(add-hook 'org-attach-after-change-hook
          (lambda (dir)
            (when (vc-backend dir)
              (shell-command
               (format "git add %s" dir)))))

附件搜索

可以使用标签和属性搜索带有附件的条目：

C-c / m ATTACHMENTS

或使用 agenda 搜索：
C-c a m ATTACHMENTS

截图捕获

;; 截图并捕获
(defun my-screenshot-capture ()
  "截图并添加到当前条目。"
  (interactive)
  (let* ((filename (format-time-string "screenshot_%Y%m%d_%H%M%S.png"))
         (filepath (expand-file-name filename org-attach-id-dir)))
    ;; 使用系统截图工具
    (shell-command (format "import %s" (shell-quote-argument filepath)))
    ;; 添加为附件
    (org-attach-attach filepath nil 'mv)))

(global-set-key (kbd "C-c c") 'org-capture)

(setq org-capture-templates

         "* TODO %^{任务}\n  %t\n  %?")
        ("n" "笔记")
        ("nw" "工作笔记" entry (file+headline "~/org/work.org" "笔记")
         "* %^{标题} :note:\n  %U\n  %?\n  %a")
        ("np" "个人笔记" entry (file+headline "~/org/personal.org" "笔记")
         "* %^{标题} :note:\n  %U\n  %?")
        ("j" "日记" entry (file+datetree "~/org/diary.org")
         "* %?\n  %U")
        ("m" "会议" entry (file+headline "~/org/meetings.org" "会议记录")
         "* 会议: %^{主题}\n  %T\n  参与者: %^{参与者}\n  %?")))

;; 附件设置
(setq org-attach-id-dir "data/")
(setq org-attach-method 'cp)  ; 默认复制文件
(setq org-attach-store-link-p t)  ; 存储链接到原文件

;; 自动保存附件变更
(add-hook 'org-attach-after-change-hook
          (lambda (dir)
            (message "附件目录已更新: %s" dir)))

快速截图附加

;; macOS 截图
(defun my-mac-screenshot ()
  "使用 macOS 截图并附加到当前条目。"
  (interactive)
  (let ((file (org-attach-dir t)))
    (shell-command "screencapture -i screenshot.png")
    (org-attach-attach "screenshot.png" nil 'mv)))

;; Linux 截图
(defun my-linux-screenshot ()
  "使用 Linux 截图并附加到当前条目。"
  (interactive)
  (let* ((filename (format-time-string "screenshot_%Y%m%d_%H%M%S.png"))
         (filepath (expand-file-name filename (org-attach-dir t))))
    (shell-command (format "scrot %s" (shell-quote-argument filepath)))
    (org-attach-attach filepath nil 'mv)))

批量附件操作

(defun my-attach-directory-recursive (dir)
  "递归添加目录中所有文件为附件。"
  (interactive "D选择目录: ")
  (let ((files (directory-files-recursively dir "\\.*[^.]$")))
    (dolist (file files)
      (unless (file-directory-p file)
        (org-attach-attach file nil 'ln)))))
