富文本标记

Org 支持多种文本标记格式。

基本标记

标记效果说明
粗体粗体用星号包裹
斜体斜体用斜杠包裹
下划线下划线用下划线包裹
删除线删除线用加号包裹
=代码=代码用等号包裹
源码源码用波浪号包裹

组合标记

可以组合使用：

*/粗斜体/*
_+下划线加删除线+_

上标和下标

H_2O 是水分子
E=mc^2 是爱因斯坦方程
a^{b}_{c} 复杂上下标

特殊字符

  • =\--- 破折号
  • \... 省略号
  • \- 软换行
  • \% 注释

实体

使用 LaTeX 风格的实体：

  • \alpha → α
  • \beta → β
  • \gamma → γ
  • \pi → π
  • \infty → ∞
  • \to → →
  • \Rightarrow → ⇒
  • \Leftarrow → ⇐

宏

定义可复用的文本：

#+MACRO: version 9.8
#+MACRO: date 2024-01-15

当前版本: {{{version}}}
日期: {{{date}}}
