处理源代码

这里的源代码指的是任何用人类可读的编程语言编写的纯文本计算机指令集合，可能包含注释。当源代码用开始和结束标记标识时，Org 可以在 Org 文档中管理源代码。

源代码块可以放在 Org 文档的几乎任何位置；不限于前言或文档末尾。但是，如果源代码块放置在 Org 注释内或固定宽度区域内，Org 无法管理它。

功能概览

Org 模式为处理源代码提供了以下主要功能：

1. 编辑 — 在专用编辑缓冲区中编辑源代码块

2. 语法高亮 — 在 Org 缓冲区中按语言语法高亮显示源代码

3. 导出 — 将源代码块导出为各种文档格式

4. 代码编织（Weaving） — 提取文档中的源代码

5. 代码纠缠（Tangling） — 从文档中提取可执行的源代码文件

6. 代码评估（Evaluation） — 在 Org 中直接执行源代码块

7. Noweb 引用 — 使用命名代码块构建更大的程序

代码块结构

代码块使用 BEGINSRC 和 ENDSRC 关键字标记。基本结构如下：

#+BEGIN_SRC 语言
源代码...

#+END_EXAMPLE

例如，一个 Emacs Lisp 代码块：

#+BEGIN_SRC emacs-lisp
(defun org-xor (a b)
  "Exclusive or."
  (if a (not b) b))

#+END_EXAMPLE

代码块还可以包含可选的名称和参数：

#+NAME: my-code
#+BEGIN_SRC python :results output
print("Hello, World!")

#+END_EXAMPLE

代码块参数

代码块可以接受多种头部参数（header arguments）来控制其行为：

#+BEGIN_SRC python :var x=1 :results output :exports both
print(f"x = {x}")

#+END_EXAMPLE

常用参数：

参数功能
:var传递变量到代码块
:results控制结果处理方式（output, value, none 等）
:exports控制导出内容（code, results, both, none）
:dir设置代码块执行目录
:session在持久会话中执行代码
:tangle控制是否纠缠到文件
:noweb启用 noweb 引用替换
:eval控制是否允许评估

头部参数

头部参数可以在多个层级设置，按优先级从低到高排列：

1. 系统范围的默认值（通过 org-babel-default-header-args）

2. 文件中通过 #+PROPERTY: 设置

3. 标题的 header-args 属性

4. 代码块自身的参数

全局设置

#+PROPERTY: header-args:python :results output :exports both

按标题设置

* 数据分析
  :PROPERTIES:
  :header-args:python: :session data-analysis :results output
  :END:

** 加载数据

#+BEGIN_SRC python
import pandas as pd
df = pd.read_csv("data.csv")

#+END_EXAMPLE

代码块环境

代码块执行时有其运行环境，包括：

  • 工作目录
  • 环境变量
  • 会话状态
  • 前置和后置代码

工作目录

#+BEGIN_SRC python :dir /tmp/work
import os
print(os.getcwd())

#+END_EXAMPLE

会话

使用 :session 参数可以在持久会话中执行代码块，保持变量和状态：

#+BEGIN_SRC python :session my-session :results output
x = 10
y = 20

print(x + y)  # 输出: 30

#+END_EXAMPLE

评估代码块

代码块可以通过以下方式评估：

快捷键功能
C-c C-c评估当前代码块
C-c C-v C-e评估当前代码块（替代方式）
C-c C-v b评估缓冲区中所有代码块
C-c C-v s评估同一子树中的所有代码块
C-c C-v f评估当前文件中的所有代码块

评估选项

可以使用 :eval 参数控制评估行为：

  • :eval yes — 始终允许评估
  • :eval no — 禁止评估
  • :eval never — 永远不评估
  • :eval query — 每次评估前询问
  • :eval never-export — 导出时不评估

安全设置

评估代码块可能涉及安全风险。Org 提供了多层安全控制：

;; 允许特定语言的评估
(setq org-babel-do-load-languages
      'org-babel-load-languages
      '((emacs-lisp . t)
        (python . t)
        (shell . t)
        (R . t)
        (sql . t)
        (dot . t)))

;; 全局安全策略
(setq org-confirm-babel-evaluate t)  ;; 评估前确认

评估结果

代码块评估结果通过 :results 参数控制。

结果类型

结果类型功能
value返回代码的返回值（默认）
output返回代码的标准输出
none丢弃结果

结果处理

处理方式功能
table将结果格式化为 Org 表格
list将结果格式化为 Org 列表
raw将结果作为原始 Org 文本插入
html将结果作为 HTML 块插入
latex将结果作为 LaTeX 块插入
org将结果作为 Org 块插入
file将结果保存为文件，插入文件链接

实用示例：生成表格

#+BEGIN_SRC python :results table
data = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
return data

#+RESULTS:

123
456
789

#+END_EXAMPLE

实用示例：生成文件（图形）

#+BEGIN_SRC python :results file :exports both
import matplotlib.pyplot as plt
plt.plot([1, 2, 3], [1, 4, 9])
plt.savefig("plot.png")
return "plot.png"

#+RESULTS:

file:plot.png

#+END_EXAMPLE

导出代码块

代码块的导出行为通过 :exports 参数控制：

值功能
code只导出代码（默认）
results只导出结果
both同时导出代码和结果
none都不导出

导出到 LaTeX

#+BEGIN_SRC python :exports both :results output
print("Hello from Python!")

#+RESULTS:

: Hello from Python!

#+END_EXAMPLE

导出到 HTML

代码块导出到 HTML 时，会根据语言应用语法高亮。使用 org-src-preserve-indentation 控制缩进。

提取源代码（Tangling）

Tangling 是从 Org 文档中提取源代码到外部文件的过程。这是"文学编程"（Literate Programming）的核心功能。

基本纠缠

#+BEGIN_SRC python :tangle hello.py
print("Hello, World!")

#+END_EXAMPLE

执行 C-c C-v t（org-babel-tangle）会创建 hello.py 文件。

纠缠参数

参数功能
:tangle yes纠缠到与 Org 文件同名的文件（加语言扩展名）
:tangle no不纠缠（默认）
:tangle filename纠缠到指定文件名
:mkdirp yes创建父目录（如需要）
:comments在纠缠输出中包含注释

纠缠命令

快捷键功能
C-c C-v t纠缠当前缓冲区
C-c C-v f纠缠当前文件
C-c C-v g纠缠项目中的所有文件

编辑源代码

Org 提供了专用的源代码编辑模式，可以在专用缓冲区中编辑代码块。

编辑命令

快捷键功能
C-c '打开专用编辑缓冲区
C-c C-c在编辑缓冲区中确认并返回 Org

编辑缓冲区

按 C-c ' 时，Org 会打开一个使用对应语言主要模式的缓冲区。编辑完成后按 C-c C-c 返回 Org 缓冲区。

编辑缓冲区行为可通过以下方式配置：

;; 编辑时不要分割窗口
(setq org-src-window-setup 'current-window)

;; 保留源代码缩进
(setq org-src-preserve-indentation t)

;; 退出编辑缓冲区时自动 tangled
(setq org-src-ask-before-returning-to-edit-buffer nil)

Noweb 引用语法

Noweb 引用允许您在一个代码块中引用另一个代码块。使用 <<名称>> 语法引用命名代码块。

#+NAME: setup
#+BEGIN_SRC python
import os

#+NAME: main

<<setup>>
def main():
    print(os.getcwd())

main()

#+END_EXAMPLE

Noweb 参数

  • :noweb yes — 启用 noweb 替换
  • :noweb no — 禁用 noweb 替换
  • :noweb eval — 仅在评估时替换
  • :noweb strip-export — 替换但在导出时去掉 noweb 标记
  • :noweb-ref — 设置默认 noweb 引用名称

Noweb 示例：构建配置文件

<<app-config>>

Babel 代码库

Org Babel 代码库（Library of Babel）是一个共享的代码块集合，可以在任何 Org 文件中调用。

加载代码库

;; 加载 Babel 代码库
(org-babel-lob-ingest "library-of-babel.org")

使用代码库中的函数

代码库中的函数通过 call- 语法调用：

#+BEGIN_SRC python :var x=5
return x * x

# 调用上面的代码块：

#+CALL: my-block(x=10)

#+END_EXAMPLE

批量执行

可以使用 Emacs 脚本批量执行 Org 文件中的代码块：

emacs --batch file.org \
      --eval '(org-babel-execute-buffer)' \
      --eval '(org-babel-tangle)'

或者使用 org-babel-do-in-current-buffer 进行更精细的控制：

;; 批量处理多个 Org 文件
(dolist (file (directory-files "/path/to/org/" t "\\.org$"))
  (with-current-buffer (find-file-noselect file)
    (org-babel-execute-buffer)
    (save-buffer)))

使用 Make 或 CI/CD

可以在 Makefile 中使用 Org Babel：

# Makefile
%.html: %.org
	emacs --batch $< --eval '(org-html-export-to-html)'

%.pdf: %.org
	emacs --batch $< --eval '(org-latex-export-to-pdf)'

tangle:
	emacs --batch main.org --eval '(org-babel-tangle)'

test: tangle
	python tests.py

实用工作流示例

数据科学工作流

#+TITLE: 数据分析报告
#+AUTHOR: 张三
#+DATE: 2024-01-15

* 数据探索

#+BEGIN_SRC python :session analysis :results output
import pandas as pd
import numpy as np

# 加载数据
df = pd.read_csv("sales_data.csv")
print(df.describe())

import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(10, 6))
df.groupby("month")["revenue"].sum().plot(kind="bar", ax=ax)
ax.set_title("月度收入")
ax.set_ylabel("收入（万元）")
plt.tight_layout()
plt.savefig("monthly_revenue.png", dpi=150)
return "monthly_revenue.png"

统计建模

from scipy import stats

# t 检验
group_a = df[df["group"] == "A"]["revenue"]
group_b = df[df["group"] == "B"]["revenue"]
t_stat, p_value = stats.ttest_ind(group_a, group_b)
print(f"t = {t_stat:.3f}, p = {p_value:.3f}")

#+END_EXAMPLE

Web 开发工作流

* API 服务器

#+NAME: server-imports
#+BEGIN_SRC python :tangle server.py
from flask import Flask, jsonify
import sqlite3

#+NAME: server-setup

app = Flask(__name__)

def get_db():
    conn = sqlite3.connect("app.db")
    return conn

#+NAME: server-routes

@app.route("/api/users")
def get_users():
    db = get_db()
    users = db.execute("SELECT * FROM users").fetchall()
    return jsonify([dict(u) for u in users])

#+NAME: server-main

if __name__ == "__main__":
    app.run(debug=True, port=5000)

#+END_EXAMPLE
